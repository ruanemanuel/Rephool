# Rephool
Devido ao avanço tecnológico e científico, temos várias maneiras de solucionar problemas com a tecnologia, essa solução é uma delas.
Obs: O código está disponível na branch **point**.

## Overview
Bem-vindo ao aplicativo Rephool, essa aplicação foi desenvolvida com o objetivo de identificar o PH de amostras utilizando o repolho roxo a partir da cor desse substrato, cuja cor será identificada por um calibrador de cores integrado com o próprio aplicativo.

## Desenvolvimento
Esse aplicativo foi desenvolvido pela linguagem de programação Dart e o framework Flutter - desenvolvido pela Google - para criação de aplicativos para qualquer sistema operacional.

## Funcionamento
Esse aplicativo funciona de duas formas: pela câmera ou pela escolha de uma foto da galeria, ele possui modo escuro e modo claro no próprio aplicativo.

### Primeira Forma
A primeira forma é identificando o PH utilizando a câmera, essa maneira terá um calibrador de cores que funciona com a câmera, isso significa que quando a câmera aponta para um local, o calibrador identifica a cor daquela imagem apontada pela câmera e após finalizar esse procedimento, ele identifica automaticamente o PH daquela cor selecionada.

### Segunda Forma
A segunda forma é identificar o PH a partir de uma foto escolhida na galeria, nessa maneira, terá um foco onde quando você clica, ele identifica de forma automática a cor naquele local apontado, depois disso quando você aperta o botão de identificação de PH, ele irá identificar o PH daquela cor e mostrar na tela.
